# OWA 메일 클리너

사내 Exchange Outlook Web App에서 제목 키워드와 날짜 범위로 메일을 찾고, 결과를 확인한 뒤 선택한 메일만 처리하는 개인용 도구입니다.

## 기능

- 한 폴더를 선택하여 제목 키워드와 날짜 범위로 검색
- 일반 첨부파일만 삭제하고 본문의 인라인 이미지는 보존
- 안 읽은 메일을 읽음으로 변경
- 메일을 영구 삭제하지 않고 `삭제된 항목`으로 이동
- 실행 전 대상 목록과 건수를 확인하고 개별 선택 해제
- 20건 단위 처리, 진행률과 성공·실패 결과 표시

## 보안 원칙

- `mail.apsfamily.com`에서만 실행됩니다.
- 외부 서버나 분석 서비스로 메일 정보를 전송하지 않습니다.
- 비밀번호, 인증 토큰, 메일 내용을 저장하지 않습니다.
- OWA의 비공개 내부 API를 사용하지 않고 표준 Exchange Web Services(EWS)만 호출합니다.

설치와 사용 방법은 `distribution/README_설치안내.md`를 참고하세요.

## 개발 검증

```powershell
npm test
npm run build
```

빌드가 성공하면 프로젝트 루트에 버전이 포함된 배포 ZIP이 생성됩니다.
