# OWA 메일 클리너 1.0.0

이 배포본은 Chrome·Edge 단독 확장 프로그램과 Tampermonkey 설치본을 함께 제공합니다. 둘 중 하나만 설치하세요.

## 방법 1: Chrome·Edge 단독 확장 프로그램

1. 배포 ZIP을 원하는 폴더에 압축 해제합니다.
2. Chrome은 주소창에 `chrome://extensions`, Edge는 `edge://extensions`를 입력합니다.
3. 화면의 `개발자 모드`를 켭니다.
4. `압축해제된 확장 프로그램을 로드`를 선택합니다.
5. 압축을 푼 폴더 안의 `extension` 폴더를 선택합니다.
6. `https://mail.apsfamily.com/owa/`에 로그인한 뒤 페이지를 새로고침합니다.

## 방법 2: Tampermonkey

1. 브라우저 확장 프로그램 스토어에서 Tampermonkey를 설치합니다.
2. `tampermonkey/Outlook_Mail_Cleaner.user.js` 파일을 브라우저로 엽니다.
3. Tampermonkey 설치 화면에서 `설치`를 선택합니다.
4. 사내 OWA에 로그인한 뒤 페이지를 새로고침합니다.

## 사용 방법

1. OWA 오른쪽 아래의 `메일 클리너` 버튼을 누릅니다. 버튼은 드래그하여 옮길 수 있습니다.
2. EWS 연결 성공과 폴더 목록이 표시되는지 확인합니다.
3. 검색할 한 폴더, 제목 키워드, 시작일, 종료일, 처리 방식을 선택합니다.
4. `대상 메일 검색`을 누릅니다.
5. 수신일, 발신자, 제목, 읽음 상태와 첨부파일을 확인하고 처리하지 않을 메일의 선택을 해제합니다.
6. `선택 항목 실행`을 누르고 마지막 확인 창에서 대상 건수와 작업을 다시 확인합니다.

## 처리 방식과 복구

- `일반 첨부파일 삭제`: 본문에 포함된 인라인 이미지는 보존합니다. 삭제한 첨부는 이 도구에서 복구할 수 없으므로 원본 파일 또는 메일 백업을 확인하세요.
- `읽음 처리`: OWA에서 해당 메일을 다시 `읽지 않음`으로 바꿀 수 있습니다.
- `휴지통 이동`: 영구 삭제하지 않습니다. OWA의 `삭제된 항목` 폴더에서 복구할 수 있습니다.

처음에는 본인이 만든 테스트 메일로 세 기능을 각각 확인한 뒤 업무 메일에 사용하세요.

## 연결 오류

- `401`, `403` 또는 EWS 인증 거부가 표시되면 OWA에 다시 로그인하고 새로고침하세요.
- 같은 오류가 계속되면 회사 Exchange 정책에서 EWS 또는 Windows 통합 인증을 차단했을 수 있습니다. 이 경우 사용자 스크립트에 비밀번호를 입력하거나 보안 기능을 우회하지 마세요.
- 단독 확장 프로그램과 Tampermonkey 설치본을 동시에 활성화하지 않는 것을 권장합니다.

## 데이터 처리

- 이 도구는 `mail.apsfamily.com`에서만 실행됩니다.
- 외부 서버로 메일 정보, 계정 정보, 인증 정보를 보내지 않습니다.
- 메일 제목과 검색 결과를 브라우저 저장소에 남기지 않습니다. 이동한 실행 버튼 위치만 현재 브라우저에 저장합니다.

## 변경 내역
