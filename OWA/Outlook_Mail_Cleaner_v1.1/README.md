# OWA 메일 클리너

사내 Exchange Outlook Web App에서 제목 키워드와 날짜 범위로 메일을 찾고, 결과를 확인한 뒤 선택한 메일만 처리하는 개인용 도구입니다.

## 기능

- 한 폴더를 선택하여 제목 키워드와 날짜 범위로 검색
- 일반 첨부파일만 삭제하고 본문의 인라인 이미지는 보존
- 안 읽은 메일을 읽음으로 변경
- 메일을 영구 삭제하지 않고 `삭제된 항목`으로 이동
- 실행 전 대상 목록과 건수를 확인하고 개별 선택 해제
- 20건 단위 처리, 진행률과 성공·실패 결과 표시

## 보안 원칙

- `mail.apsfamily.com`에서만 실행됩니다.
- 외부 서버나 분석 서비스로 메일 정보를 전송하지 않습니다.
- 비밀번호, 인증 토큰, 메일 내용을 저장하지 않습니다.
- OWA의 비공개 내부 API를 사용하지 않고 표준 Exchange Web Services(EWS)만 호출합니다.

설치와 사용 방법은 `distribution/README_설치안내.md`를 참고하세요.

## 개발 검증

```powershell
npm test
npm run build
```

빌드가 성공하면 프로젝트 루트에 버전이 포함된 배포 ZIP이 생성됩니다.

## 휴지통 정리

1. 처리 방식에서 `휴지통 정리`를 선택합니다. 기본 지운 편지함으로 고정됩니다.
2. 제목과 날짜를 비우면 전체 제목·전체 기간을 조회합니다. 기간을 지정하려면 시작일과 종료일을 함께 입력합니다.
3. 검색 결과를 수신일 오래된 순·최신순 또는 용량 큰 순·작은 순으로 정렬합니다. 날짜는 삭제일이 아닌 수신일입니다.
4. 체크박스를 선택한 뒤 `선택 항목 비우기`를 누르거나, `검색 결과 전체 비우기`로 조회된 메일 전부를 처리합니다. 검색 직후에는 모두 미선택입니다.
5. 확인 창에서 대상 건수·용량·조건을 확인합니다. 중단 요청은 진행 중 요청이 끝난 뒤 적용됩니다.

지운 편지함 바로 아래의 일반 메일만 대상으로 하며 하위 폴더·일정·연락처는 제외합니다. 실행 직전 이동·삭제된 메일은 건너뜁니다. 조회 실패·중단·10만 건 조회 상한 도달 시 기간을 좁혀 재검색해야 합니다. 처리 결과에 성공·실패·건너뜀·미처리 건수를 표시합니다.

비우기는 SoftDelete 방식입니다. 지운 편지함에서 제거한 메일은 복구 가능 항목으로 이동하며, 복구 여부와 보존 기간은 회사 서버 정책을 따릅니다. 이 도구에는 복구 기능이 없습니다.

용량은 첨부를 포함한 메일 크기이며 1KB = 1,024바이트입니다. 미확인 용량은 합계에서 제외하여 별도 건수로 표시합니다. 메일 크기 합계가 실제 확보되는 사서함 용량을 보장하지는 않습니다.

기존 설치를 업데이트할 때는 새 확장 폴더를 다시 로드하거나 Tampermonkey 스크립트를 교체한 뒤 OWA 페이지를 새로고침하세요. 화면 상단의 v1.1.0을 확인하세요.

개발 검증: `node tests/browser-smoke.cjs`는 Playwright와 Edge가 설치된 환경에서 모의 EWS 응답으로 화면 동작을 검증합니다. 실제 사내 EWS 삭제 검증은 별도로 필요합니다.
