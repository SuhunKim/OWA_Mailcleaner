# 순천향 메일클리너 — 관리자·수정 가이드

기능을 요청한 사람이 필요한 기능을 직접 고칠 수 있도록 구조, 사이트 의존 지점, 진단 방법, 검증 절차를 정리합니다. 사용법은 [README.md](README.md)를 보세요. 마지막 갱신: 2026-11-11.

## 1. 구조

| 파일 | 역할 |
|---|---|
| `Program.cs` | 앱 전체(화면, 로그인 감지, 검색, 읽음/휴지통/비우기 실행, 진단) |
| `ReadMailbox.js` | 사이트 목록 화면을 **읽기만** 하는 스크립트(실행 파일에 내장). 메일을 열지 않습니다. |
| `SchMailCleaner.csproj` | .NET 8 WPF + WebView2 프로젝트 |
| `build.ps1` | 단일 EXE 배포 빌드 |

동작 원리: 앱은 사이트(hg.sch.ac.kr)를 **내장 브라우저(WebView2)** 로 열어 둡니다. 로그인은 사용자가 사이트 화면에서 직접 하고, 이후 앱이 사이트 화면의 DOM을 읽어 목록을 만들며, 실행할 때는 **사이트의 자기 버튼(링크)을 그대로 클릭**합니다. 별도 URL이나 API를 추측해 호출하지 않습니다. 로그인 후에는 브라우저 창을 숨겨 둡니다.

`Program.cs` 주요 위치(검색은 이름으로):

- `SearchAsync` — 폴더를 열고 페이지별로 읽은 뒤 조건으로 거름
- `RunActionAsync` — 선택 메일에 읽음/휴지통 실행, 마지막 페이지부터 처리, 결과 확인, 자동 재검색
- `UiClick_ClearTrash` — 지운 편지함 비우기
- `OnTimerTick` / `SetLoggedIn` — 로그인 감지와 창 숨김
- `OpenFolderAsync`, `GoToPageForActionAsync`, `RunInFrameAsync` — 사이트 프레임에서 스크립트 실행
- `UiClick_Dump` — 진단용 화면 구조 복사(`Ctrl+Shift+D`)

## 2. 사이트 의존 지점 (사이트 화면이 바뀌면 여기를 확인)

2026-11-11 실제 화면에서 확인한 값입니다.

| 용도 | 값 | 위치 |
|---|---|---|
| 메일 목록 프레임 | `frame#Start` (메뉴는 `frame#Main`) | 전체 |
| 계정 식별 | 목록 프레임의 `#UID` (숨은 입력) | `ReadMailbox.js` |
| 폴더 이름 | `.list_content h2` (없으면 첫 `h2`) | `ReadMailbox.js` |
| 총 메일 건수 | `#msgTotalCount` | `ReadMailbox.js` |
| 현재 페이지/전체 페이지 | `#targetPage`와 그 부모 텍스트의 `/ N` | `ReadMailbox.js` |
| 메일 행 | `tr[id^="mail_list-"]`, 셀 5개: 0=체크박스+상태 아이콘, 1=보낸이, 2=제목(`a[title]`), 3=받은날짜(`yyyy.MM.dd HH:mm`), 4=크기(`B/KB/MB/GB`) | `ReadMailbox.js` |
| 폴더 열기 | 폴더 링크 `#menu_01`(받은), `#menu_10`(내게 쓴), `#menu_02`(보낸), `#menu_03`(지운) | `s_oFolders` |
| 페이지 이동 | 사이트 함수 `gotoPage(n)` (`n`은 0부터) | `MoveToPageAsync`, `GoToPageForActionAsync` |
| 읽음 처리 | 링크 `href="javascript:checkedSetRead(true);"` | `RunActionAsync` |
| 휴지통 이동 | 링크 `href="javascript:deleteMessages(false);"` | `RunActionAsync` |
| 지운 편지함 비우기 | 링크 `onclick="submitTrashboxClear(false);"` | `UiClick_ClearTrash` |
| 행 선택 | 각 행의 `input[type="checkbox"]` | `RunActionAsync` |
| 로그인 감지 | 목록 프레임에 `#menu_01`과 `#UID`가 모두 있음 | `OnTimerTick` |
| 사이트 확인창 | 실행 중에만 자동 수락(`ScriptDialogOpening`) | `OnLoaded` |

참고: 완전 삭제는 `deleteMessages(true);`, 안 읽음 처리는 `checkedSetRead(false);` 입니다(현재 미사용).

## 3. 사이트 화면이 바뀌어 동작이 깨졌을 때

증상 예: `메일 목록 형식이 변경되었습니다`, `메일 화면을 찾을 수 없습니다`, `사이트의 실행 버튼을 찾지 못했습니다`, 검색이 0건/실패.

1. 앱에서 `Ctrl+Shift+D`를 누르면 현재 화면의 버튼·메뉴 이름·호출 함수와 목록 행의 상태 아이콘 구조가 **클립보드에 복사**됩니다(메일 제목·본문·비밀번호는 제외). 메모장에 붙여넣어 확인하세요.
2. 위 2장의 표와 비교해 달라진 선택자·함수명을 찾아 `ReadMailbox.js` 또는 `Program.cs`의 해당 문자열을 고칩니다.
3. 빌드 후 4장의 시험을 합니다.

`개발자 도구` 버튼(헤더)으로 사이트 화면의 Network/Console을 직접 볼 수도 있습니다.

실제로 한 번 겪은 사례: 사이트 개편으로 제목 선택자(`.list_content h2`)가 사라져 조회가 실패했습니다. 오류 문구에 앱이 읽은 값을 함께 표시하면 원인 파악이 빠릅니다.

## 4. 수정 후 확인 순서 (실제 메일 사용)

반드시 **지워도 되는 테스트 메일**로 하세요. 변경 작업은 되돌릴 수 없는 경우가 있습니다.

1. 로그인 → 로그인 창이 사라지고 작업 화면이 나오는가
2. 키워드 비움 + 기본 기간으로 검색 → 건수가 사이트의 목록 건수와 맞는가(페이지 수 × 페이지당 건수)
3. 제목 키워드/보낸사람/날짜/용량 필터 각각과 조합 → 목록이 맞게 줄어드는가, 일치 없음 문구가 나오는가
4. 테스트 메일 1건만 체크 → 읽음 처리 → 사이트에서 읽음으로 바뀌었는가, 앱의 결과 문구가 맞는가
5. 테스트 메일 1건 → 휴지통 이동 → 지운 편지함에 들어갔는가, 받은 편지함 건수가 줄었는가
6. (영구 삭제) 지운 편지함에 테스트 메일만 있을 때 비우기 → 경고·건수 표시, 결과 확인
7. 중간에 `중단 요청`, 로그인 만료(로그아웃 후), 조건 변경 시 재검색 요구가 정상인가

## 5. 기능 추가 시 지침

- **먼저 근거를 확보**합니다. 사이트의 해당 버튼이 호출하는 함수/요청을 `Ctrl+Shift+D` 또는 개발자 도구로 확인하고, 추측한 URL·함수명으로 쓰기 기능을 만들지 않습니다.
- 변경 작업은 **자동 재시도 금지**: 응답을 확인하지 못하면 '결과 미확인'으로 두고 중단합니다(중복 처리 방지).
- 실행 전 대상 건수 확인, 실행 후 서버 상태 재확인(건수/행 변화)을 유지합니다.
- 계정(`#UID`)과 폴더가 검색 때와 같은지 실행 전에 확인합니다.
- 메일 용량은 **메일 전체 용량**입니다. 첨부 용량이나 확보 공간으로 표시하지 않습니다.

## 6. 미구현·미확인 항목 (인계)

| 항목 | 상태 | 이어서 할 일 |
|---|---|---|
| 일반 첨부파일만 삭제 | 미구현, **사이트 지원 여부 미확인** | 첨부가 있는 메일의 상세 화면에서 첨부 삭제 기능이 있는지 확인(`Ctrl+Shift+D`/개발자 도구). 없으면 불가로 확정. 전체 메일 삭제를 대안으로 자동 채택하지 않음 |
| 안 읽음 판별·`상태`/`첨부` 열 | 미구현 | 목록 행 `cells[0]`의 아이콘 구조(`MailRow.Status`로 이미 수집 중)를 해석해 `Unread`/`HasAttach` 설정. 읽음 처리 모드는 안 읽은 메일만 대상으로 |
| 휴지통 이동·비우기·다른 폴더 검색 | 구현됨, **실제 검증 미완료** | 4장 시험 수행 |
| 비밀번호 저장 | 구현됨(브라우저 기능), 검증 미완료 | 로그인 시 저장 제안·자동 채움 확인 |

## 7. 문제 확인용 기록

- `%LOCALAPPDATA%\SchMailCleaner\state.log`: 로그인 감지, 창 표시·숨김 시점(UTF-8).
- 앱 하단 상태줄 문구: 결과·오류의 1차 단서. 오류를 보고할 때는 이 문구를 그대로 전달하세요.
