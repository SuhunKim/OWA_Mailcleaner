# 순천향 메일클리너

순천향 그룹웨어 메일(https://hg.sch.ac.kr)에서 조건에 맞는 메일을 찾아 **읽음 처리 / 휴지통 이동**을 한꺼번에 처리하고, **지운 편지함을 비우는** Windows 프로그램입니다. 브라우저 확장이나 Tampermonkey 설치가 필요 없습니다. 기존 OWA 메일클리너와 같은 사용 흐름(조건 입력 → 검색 → 체크 → 실행)입니다.

- 이슈: https://github.com/SuhunKim/OWA_Mailcleaner/issues/11
- 유지보수·수정 방법: [ADMIN_GUIDE.md](ADMIN_GUIDE.md)
- 마지막 갱신: 2026-11-11

## 실행

1. `publish\SchMailCleaner.exe`를 실행합니다. 설치가 필요 없습니다. (파일 크기 약 155MB — .NET 런타임이 들어 있습니다.)
2. PC에 **Microsoft Edge WebView2 Runtime**이 있어야 합니다. Windows 11과 최신 Windows 10에는 보통 설치되어 있습니다.
3. 처음 열리는 **로그인 창**에서 사원번호·비밀번호로 로그인합니다. 로그인되면 창이 자동으로 사라지고 작업 화면이 나타납니다.
4. 조건을 입력하고 `대상 메일 검색` → 대상 체크 → `선택 항목 실행`.

## 사용법

| 항목 | 설명 |
|---|---|
| 폴더 | 받은 편지함 / 내게 쓴 편지함 / 보낸 편지함 / 지운 편지함 중 하나만 검색 |
| 제목 키워드, 보낸사람 이름 | 일부 글자만 입력해도 되고 대소문자는 구분하지 않습니다. **둘 다 비우면 기간 안의 전체 메일**을 보여 줍니다. |
| 시작일 / 종료일 | 기본값은 오늘 기준 최근 30일(오늘−29일 ~ 오늘). 종료일은 23:59까지 포함합니다. |
| 최소 용량(MB) | 메일 **전체** 용량 기준입니다. 첨부파일만의 용량이 아닙니다. 0이면 제한 없음. |
| 처리 방식 | `읽음 처리`(기본) / `휴지통 이동`. `일반 첨부파일 삭제`는 아직 사용할 수 없습니다. |
| 검색 결과 | 찾은 메일은 **모두 체크된 상태**로 나옵니다. 처리하지 않을 메일은 체크를 해제하세요. |
| 조건 변경 | 검색 후 조건을 바꾸면 결과가 무효가 되어 **다시 검색해야** 실행할 수 있습니다. |
| 실행 후 | 건수별 결과(반영 확인 / 결과 미확인 / 건너뜀 / 미처리)를 보여 주고 **자동으로 다시 검색**해 실제 남은 상태를 표시합니다. |
| 중단 요청 | 작업 중 표시되며, 현재 요청이 끝난 뒤 멈춥니다. |
| 지운 편지함 비우기 | 화면 아래 빨간 영역. 앱이 지운 편지함을 열어 사이트의 `비우기`를 실행합니다. **되돌릴 수 없으며** 건수를 표시하고 별도로 확인합니다. |
| 사이트 화면 보기 | 숨겨진 로그인/사이트 창을 다시 엽니다. |
| 로그아웃·세션 정리 | 로그인 세션을 지웁니다. 저장된 비밀번호는 유지됩니다. |

### 로그인 정보 기억

로그인 카드의 `로그인 정보 기억`(기본 켜짐)을 켜면 로그인 창에서 브라우저가 비밀번호 저장을 제안하고 다음부터 자동으로 채워 줍니다. 저장 정보는 이 앱 전용 브라우저 프로필에 Windows 사용자 계정으로 암호화되어 보관되며 앱이 직접 읽거나 전송하지 않습니다. 체크를 끄면 저장된 비밀번호를 삭제합니다. 자동 로그인은 하지 않습니다.

## 안전 장치

- 항상 사용자가 선택(체크)한 메일에만 실행합니다. 실행 전에 건수와 작업을 확인합니다.
- 결과가 확인되지 않으면 **자동으로 재시도하지 않고** 중단하며 '결과 미확인'으로 표시합니다.
- 앱은 `hg.sch.ac.kr` 밖으로 이동하지 않으며 새 창·외부 이동을 차단합니다.
- 중복 실행을 막습니다.
- 사이트의 `읽음`/`삭제`/`비우기` 버튼과 같은 호출만 사용합니다(별도 URL을 만들어 호출하지 않음).

## 저장되는 데이터 (모두 `%LOCALAPPDATA%\SchMailCleaner`)

| 위치 | 내용 |
|---|---|
| `Browser\` | 앱 전용 브라우저 프로필(세션, 저장된 비밀번호) |
| `remember-login` | 로그인 정보 기억 설정(`true`/`false`) |
| `state.log` | 로그인 창 표시·숨김 등 상태 전환 기록(메일 내용·계정 정보 없음, UTF-8) |

배포 파일(EXE)에는 개인 정보가 들어 있지 않습니다.

## 알려진 제한

- **일반 첨부파일 삭제**: 사이트에 첨부만 삭제하는 기능이 있는지 확인되지 않아 제공하지 않습니다.
- **결과 판정**: 읽음 처리와 휴지통 이동은 메일별로 확인합니다. 읽음은 목록의 상태 표시가 읽음일 때만, 휴지통 이동은 원본에서 사라지고 지운 편지함에 같은 메일(ID·내용)이 새로 보일 때만 `반영 확인`입니다. 확인하지 못하면 `결과 미확인`으로 남기고 이후 요청을 중단하며 자동 재시도하지 않습니다. 이 판정은 아직 실제 사이트에서 시험하지 않았습니다.
- **안 읽음 / 첨부 표시**: 검색 결과의 `상태`·`첨부` 열은 현재 `-`로 표시됩니다(목록 아이콘 해석 미구현). 읽음 처리 모드에서도 안 읽은 메일만 골라 주지 않습니다.
- 사이트 화면 구조가 바뀌면 조회·실행이 실패할 수 있습니다. 대처 방법은 [ADMIN_GUIDE.md](ADMIN_GUIDE.md)를 보세요.
- 외부 SSO·팝업 로그인은 지원하지 않습니다.
- 조회 중 새 메일이 도착하면 페이지 구성이 달라져 오류로 중단될 수 있습니다. 다시 검색하세요.

## 검증 상태 (2026-11-11, 실제 계정 사용)

| 기능 | 상태 |
|---|---|
| 로그인 창 분리·로그인 감지·창 숨김 | 확인함 (사용자 확인, `state.log`) |
| 받은 편지함 검색(371건, 8페이지), 최소 용량 필터 | 확인함 (이전 UI 버전) |
| 읽음 처리 | 사용자가 동작 확인 (이전 UI 버전) |
| 현재 UI의 폴더·제목·보낸사람·기간 필터와 체크박스 선택·자동 재검색 | **미검증** |
| 휴지통 이동 | **미검증** |
| 지운 편지함 비우기 | **미검증** |
| 내게 쓴·보낸·지운 편지함 검색 | **미검증** (받은 편지함만 확인) |
| 비밀번호 저장·자동 채움 | **미검증** |
| 배포 EXE(단일 파일) 실행·로그인 페이지 표시 | 확인함 (로그인 이후 동작은 미확인) |

미검증 기능은 **지워도 되는 테스트 메일 1~2건**으로 먼저 시험하세요.

## 빌드 (수정한 뒤 다시 만들 때)

.NET 8 SDK(Windows)가 필요하고, 최초 1회 NuGet 접근이 필요합니다.

```powershell
cd SchMailCleaner
.\build.ps1          # 결과: .\publish\SchMailCleaner.exe (단일 파일, 런타임 포함)
```

개발 중 빠른 실행: `dotnet build -c Release` 후 `bin\Release\net8.0-windows\SchMailCleaner.exe`.
